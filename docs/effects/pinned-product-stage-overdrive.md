# Pinned Product Stage — Overdrive

## Purpose

A scroll-driven product storytelling stage for SaaS launches, agent systems, premium service offers and product teardowns.

## Chapters

1. Core identity
2. Exploded architecture
3. Visible intelligence and telemetry
4. Evidence and outcomes
5. Final deploy / CTA state

## Interaction

- Internal scroll timeline with damping
- Sticky product object
- Chapter navigation buttons
- Pointer parallax
- Layer explosion and convergence
- Scan and orbit states
- Live telemetry and proof metric
- Mobile and reduced-motion layouts

## Production pattern

Replace the procedural NOX object with a real product image, 3D render, dashboard screenshot stack or service package. Replace the five section definitions with product-specific copy, metrics and CTA content. No network requests or additional dependencies are required.
